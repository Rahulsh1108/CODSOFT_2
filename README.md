# Task 2: Student Grade Calculator

## Project Description
The Student Grade Calculator is a console-based Java application developed as part of my CodSoft Java Programming Internship.

This program takes the student's name and marks in five subjects as input. It calculates the total marks, percentage, grade, and pass/fail result.

## Features
- Accepts student name.
- Takes marks for five subjects.
- Validates marks between 0 and 100.
- Calculates total marks.
- Calculates percentage.
- Assigns grades based on percentage.
- Checks pass or fail status.
- Displays the final result.

## Grading System

| Percentage | Grade |
|---|---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | E |
| Any subject below 33 | F (Fail) |

## Technologies Used
- Java
- IntelliJ IDEA
- Scanner Class
- Arrays
- Loops
- Conditional Statements
